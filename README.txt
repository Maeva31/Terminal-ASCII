Terminal Fun
====================

Lance:
    MENU_TERMINAL_FUN.cmd

Contenu:
- MENU_TERMINAL_FUN.cmd : menu principal
- MATRIX_LOCAL.ps1 : pluie Matrix locale
- METEO.ps1 : meteo avec saisie de ville
- QR_CODE.ps1 : QR code terminal
- POKEMON_ASCII.cmd : Pokemon par numero Pokedex
- COMMANDES.txt : liste des commandes

Important:
- Sous PowerShell, utilise curl.exe et non curl.
- Ctrl+C arrete la plupart des animations.
- Star Wars utilise le client Telnet Windows et depend d'un serveur public.
- Les Pokemon sont charges depuis un depot public GitHub.
